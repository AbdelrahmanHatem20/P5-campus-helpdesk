# P5-campus-helpdesk

## Project 5 - Campus Helpdesk and Maintenance Tickets

A campus helpdesk system for managing maintenance requests and support tickets.

---

# Project Structure

The project is organized into the following main directories:

- `.github/` → GitHub Actions workflows and Pull Request templates
- `backend/` → Backend application
- `frontend/` → Web frontend application
- `mobile/` → Mobile application
- `ai/` → AI components
- `data/` → Data-related files
- `docs/` → Project documentation
- `scripts/` → Automation scripts
- `ui-ux/` → UI/UX resources

---
